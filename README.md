## Project Overview
A web-based transportation system that connects passengers (users), drivers, and admins. Key features include:
- User registration and login
- Ride booking and tracking
- Payment processing (multiple options)
- Driver ride acceptance and status updates
- Profile management, ratings/reviews, safety features
- Admin oversight (user/driver management, reports)

Built as a web application (not mobile).

## Repository Contents
- **Requirements gathering** summary and client personas simulation
- **User stories** for User, Driver, and Admin personas
- **Use Case Diagram** (covering major actors and functions)
- **Detailed Use Case Scenarios** (e.g., User Registration)
- **Test Cases** (focus on registration module and more)
- **Design Patterns** applied (Singleton for DB connection, Strategy for payments)

## Technologies & Patterns
- Singleton Pattern (database utils)
- Strategy Pattern (payment service)
- Likely Java/Spring or similar backend (based on patterns used)
